Chips for groups and filters — the visible surface of per-group visibility.

```jsx
<Tag hue="var(--hue-sky)" selected>Soccer</Tag>
<Tag hue="var(--hue-rose)" soft="var(--hue-rose-soft)">Family</Tag>
```

Every group in Plannit owns one of the six `--hue-*` tokens; reuse the same hue for that group everywhere (chip dot, event spine, avatar ring).
